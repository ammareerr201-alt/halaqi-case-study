# Contributing

This repository is a public portfolio case study for Halaqi.

Contributions should be limited to:

- Typo fixes.
- Broken link reports.
- Documentation clarity improvements.
- High-level architecture explanation improvements.
- Accessibility or readability suggestions.

Do not submit production source code, secrets, screenshots with private data, Firebase configuration, signing material, deployment credentials, customer data, barber data, admin data, or internal analytics.

## Pull Requests

Open small, focused pull requests. If a screenshot is included, it must use demo or fully anonymized data and must pass the checklist in `screenshots/README.md`.

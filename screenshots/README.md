# Screenshots

Approved public screenshots have not been added yet.

This repository should not include fake production screens. Add screenshots only after replacing or blurring private data and confirming the image represents the real product safely.

## Required Privacy Checks

Before publishing any screenshot, remove or blur:

- Customer names.
- Barber names that are not approved for public use.
- Phone numbers.
- OTP codes.
- Appointment details.
- Locations, private addresses, and coordinates.
- Chat messages.
- Wallet balances and payment details.
- Admin records.
- Analytics values that reveal private business data.
- Firebase identifiers.
- Internal URLs.
- Staff names or private emails.

## Recommended Capture List

| Screenshot | Privacy instructions |
| --- | --- |
| Customer home | Use demo data; blur names, exact locations, ratings counts if sensitive, and any personal identifiers. |
| Barber profile | Use an approved barber or demo profile; blur phone numbers, private address details, and unavailable internal fields. |
| Booking flow | Use demo service and time; remove real appointment IDs, customer names, phone numbers, and notes. |
| Appointment details | Use a cancelled or demo appointment; blur customer, barber, time, address, and payment information. |
| Barber dashboard | Use demo data; hide wallet balance, customer names, real queue data, and private performance numbers. |
| Admin dashboard | Use staging/demo data only; blur all user records, analytics values, staff names, internal IDs, and moderation details. |
| QR analytics | Use sample campaign data; blur source IDs, campaign internals, and private conversion numbers. |

Use consistent image widths, concise captions, and avoid screenshots that expose operational tools before review.

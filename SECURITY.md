# Security Policy

This repository is a public case study for Halaqi. It intentionally excludes production source code, secrets, Firebase configuration, customer data, signing material, private URLs, and deployment credentials.

## Reporting

Do not publish secrets, customer information, internal URLs, private screenshots, or vulnerability details in public issues.

Until a dedicated security contact is published, use Ammar Hussein's GitHub profile to request a private reporting channel.

## Scope

In scope:

- Accidental exposure in public documentation.
- Broken public links that could mislead visitors.
- Diagrams or screenshots that reveal sensitive information.

Out of scope:

- Halaqi production source code.
- Firebase, Codemagic, app-store, or signing configuration.
- Customer, barber, admin, appointment, payment, wallet, support, or analytics data.

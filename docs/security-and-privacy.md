# Security And Privacy

This case study is designed for public portfolio use only.

Do not publish:

- Production source code.
- Firebase config files.
- API keys.
- Firebase project IDs or app IDs.
- Secrets or environment variables.
- Customer, barber, admin, appointment, chat, location, wallet, support, or analytics records.
- Phone numbers.
- Private email addresses.
- Signing certificates, keystores, provisioning profiles, or app-store credentials.
- Private repository URLs.
- Internal deployment logs.

Allowed public content:

- High-level architecture diagrams.
- Public store links.
- Public website or landing page links.
- Technology stack and engineering decisions.
- Lessons learned.
